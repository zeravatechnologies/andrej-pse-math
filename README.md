# PSE Math

A research workbench for mathematical conjectures: build a conjecture, push the evidence for it, and refute it the moment a counterexample appears, with every move kept in a journal.

- **Download:** <https://labs.zeravatech.ca/>, for Ubuntu and Windows, with SHA-256 checksums
- **Licence:** GPL-3.0-or-later; see [LICENSE](LICENSE) and [NOTICE](NOTICE)

The application is in [`pse-research/`](pse-research/); its design is in `PSE_MATH_RESEARCH_BUILD.txt` and `PSE_MATH_RESEARCH_ADDENDUM.txt`.
